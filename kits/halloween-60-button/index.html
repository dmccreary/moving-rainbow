    Halloween Costume Kit

    Light up your Halloween costume with a strip of 60 color LEDs! One button on the costume changes the light show. Press it to switch from a glowing pumpkin to flying bats, bubbling potions or a lightning storm.

    Pixel says...

    Hi, I'm Pixel! Halloween is my favorite night to glow. In these labs you'll write every spooky pattern yourself. Then you'll wear your code to the party. Let's light this up!

    What You'll Learn

    These labs start with one blinking light and end with a full costume program. Along the way you'll learn to:

    • Run your first program on a real computer chip
    • Read a button press in code
    • Make lights move, fade and sparkle
    • Use lists (ordered groups of values) to track many bats, bubbles or eyes
    • Build a state machine (a program that can be in one of several modes)

    What's in the Kit

    Part Notes
    Raspberry Pi Pico The small computer that runs your code
    60-pixel WS2812B LED strip 1 meter of NeoPixels (60 pixels per meter)
    One momentary push button A button that only counts while you hold it down
    Jumper wires Or solder the wires for a costume that holds up to dancing
    USB battery pack Powers the Pico and the strip while you walk around
    USB cable One that carries data, for programming
    Tape, safety pins or a sewn sleeve To hold the strip on your costume

    Watch out!

    Some battery packs turn off when the power draw is very low. If your costume goes dark by itself, try a different battery pack. Pick one that stays on for small devices.

    How the Parts Connect

    The strip needs only three wires, and the button needs two.

    From To What it does
    Strip DIN (data in) Pico GP0 (pin 1) Sends the colors to the strip
    Strip +5V Pico VBUS (pin 40) Power for the strip, straight from USB
    Strip GND Pico GND (pin 38) The shared return path
    Button, one side Pico GP15 (pin 20) The Pico reads the button here
    Button, other side Pico GND (pin 18) Pressing connects GP15 to ground

    The button uses the Pico's internal pull-up resistor (a part inside the chip that holds the pin at 1). That means you need no extra parts. The pin reads 1 when the button is up and 0 when you press it.

    Look for the small arrows printed on the strip. They point away from DIN. Connect the Pico to the end where the arrows start.

    The config.py File

    Every program reads its settings from one shared file called config.py. You never have to remember pin numbers.

    # Halloween Costume Kit Configuration file
# Filename: config.py
# Version: 1.0.0
#
# This file contains the hardware configuration for the Halloween costume kit.
# It is imported by each program.
#
# The kit has a 60-pixel NeoPixel strip on GPIO 0 and one push button
# wired from GPIO 15 to GND.
NEOPIXEL_PIN = 0
NUMBER_PIXELS = 60
BUTTON_PIN = 15

# 60 pixels at full brightness can pull more than 3 amps, which is too much
# for a USB battery pack. Every program multiplies its colors by this number.
# 0.25 means one quarter brightness. Keep it at 0.3 or lower on battery power.
BRIGHTNESS = 0.25

    Staying Safe on Battery Power

    Each pixel has a red, a green and a blue LED inside. At full brightness, each LED can use about 20 milliamps (mA). For 60 white pixels, that is:

    \[ 60 \times 3 \times 20 \text{ mA} = 3600 \text{ mA} \]

    That is too much for most USB battery packs. So every program multiplies its colors by BRIGHTNESS. With BRIGHTNESS = 0.25, the most the strip can use is about 900 mA. The colors still look bright in the dark!

    Getting Your Code onto the Costume

    Use the upload-code.sh script to copy every lab onto the Pico. Close Thonny first, because only one program can use the Pico at a time.

    cd src/kits/halloween-60-button
./upload-code.sh

    To make the costume start its light show by itself, save 20-main-template.py on the Pico with the name main.py. The Pico runs main.py every time it gets power.
